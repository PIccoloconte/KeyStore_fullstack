# Videogame Key Store
<img width="1902" height="913" alt="KeyStore" src="https://github.com/user-attachments/assets/e564ef34-fda6-4d05-acdc-10db250cde21" />

Welcome to the GitHub repository of **Videogame Key Store**, a comprehensive key store full stack web application developed with Next.js, React, Node.js,Typescript, Tailwind CSS, and other cutting-edge libraries.
<br>I used **Turborepo** to develop both the front end and the back end together.

## Live demo:
<a>https://key-store-fullstack-2sz3.vercel.app/</a>

## Key Features:

* **Dedicated Api:** Creation REST API for games , authentication , cart and orders.
* **Modern User Interface:** Appealing and responsive design powered by Tailwind CSS.
* **Advanced Form Management:** Robust and validated forms with Formik and Yup.
* **User Authentication:** Registration, login, and password recovery for a personalized experience.
* **Cart and Wishlist Management:** Add, remove, and modify products in the cart.
* **Simplified Checkout Process:** Integrated address entry, payment witch cart and paypal sdk.
* **Detailed Product Pages:** Comprehensive product information with images descriptions, and System Requirements.

## Project Pages:



 * `HomeScreen.js`: Main page with carousel , category products and general info.
 * `ProductsPage.js`: List of all available products filtere by platform or searchebar value.
 * `Product.js`: Detail page of a single product.
 * `Login.js`: Login page for registered users.
 * `Register.js`: Registration page for new users.
 * `Cart.js`: Management of the shopping cart.
 * `Checkout.js`: Checkout and payment process.
 * `purchaseCodes.js`: Show purchased keys after checkout.
 * `user.js`: Show user information and purchased keys.

## Installation and Startup:

1.  Clone the repository: `git clone https://github.com/PIccoloconte/TechCommerce-React.git`
2.  Install dependencies: `npm install`
3.  Start the application: `npm start`
